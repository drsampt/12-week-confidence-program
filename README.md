# Talk & Act Like a CEO — 12-Week Confidence Program

A free, open-source alternative to paid confidence programs. Answer 10 questions and get a fully personalized 12-week executive presence curriculum — built around your specific goals, challenges, and learning style.

## What Makes This Different

| This Program | Typical Apps (RiseGuide, etc.) |
|---|---|
| Full 12-week plan from day 1 | Generic daily lessons |
| Personalized from 10 targeted questions | 3 pre-set tracks |
| 60 structured daily sessions | Disconnected content |
| AI-generated personalized content | One-size-fits-all |
| Free & open source | Subscription |
| No account, no email | Requires signup |

## The 4 Phases

| Phase | Weeks | Focus |
|---|---|---|
| CEO Foundation | 1–3 | Identity, Mindset, Physical Presence |
| Executive Communication | 4–6 | Voice, Clarity, Storytelling |
| Influence & Authority | 7–9 | Social Intelligence, Persuasion, Pressure |
| Mastery & Identity | 10–12 | Brand, Gravitas, Integration |

## Getting Started

No build step required. Open `index.html` in a browser or deploy to GitHub Pages:

1. Fork this repo
2. Go to Settings → Pages → Deploy from `main` branch
3. Your program is live at `https://yourusername.github.io/12-week-confidence-program`

## AI-Personalized Content (Optional)

Each week includes buttons to generate personalized affirmations, exercises, and challenges using Claude AI. To use this:

1. Get a free API key at [console.anthropic.com](https://console.anthropic.com)
2. Click any "Generate" button in the program
3. Enter your key when prompted — it's stored only in your browser, never sent to any server

## Tech Stack

- Zero dependencies — plain HTML, CSS, ES Modules
- Works offline after first load
- Progress saved to `localStorage`
- Deploys to any static host (GitHub Pages, Netlify, Vercel)
